# Architecture

## Principles

- **Jellyfin is the source of truth.** The app caches images (bounded), a Home snapshot and parsed subtitles; everything else is fetched. Watch state is written through the server and re-read.
- **Business logic is platform-independent and tested.** Anything that can be expressed without UIKit/AVFoundation lives in `FoyerCore`.
- **The UI never knows the engine.** Screens talk to `PlaybackCoordinator`; the coordinator talks to a `PlaybackEngine`.
- **No God objects.** `AppEnvironment` only wires dependencies; feature view models own their state; the coordinator is the only stateful playback object.

## Data flow

```
SwiftUI views ── observe ──▶ view models (@Observable, @MainActor)
                                   │ async/await
                                   ▼
                           JellyfinClient (Sendable, URLSession transport)
                                   │
                                   ▼
                            Jellyfin HTTP API
```

`AppEnvironment` (one instance, in the SwiftUI environment) exposes `sessionStore`, `preferences`, `images`, `capabilities`, `client` and the current `playback` coordinator. `RootView` switches between onboarding and `MainTabView` based on `sessionStore.active`. Tabs are Home, one tab per video library, Search and Settings.

## Session and security

- Tokens live in the Keychain (`KeychainStore`, generic password, after-first-unlock). Account metadata (server URL, user id/name) lives in UserDefaults.
- `JellyfinClient` is a thread-safe class holding the token; it registers the token with the logger so it is redacted anywhere.
- A 401 on an authenticated request triggers `onSessionExpired`, which drops the token and shows onboarding with the server pre-filled.
- Server URL input is normalised by `ServerAddress` (https first, then http; explicit schemes respected; other schemes rejected). No certificate validation is disabled.

## Concurrency model

- View models, `SessionStore`, `Preferences`, `AppEnvironment`, `PlaybackCoordinator` and both engines are `@MainActor`.
- Networking runs on URLSession; decoding happens on the calling task. `JellyfinClient` is `@unchecked Sendable` with a lock around the mutable token.
- `ImagePipeline` coalesces in-flight requests with a lock and decodes through ImageIO thumbnails (memory ∝ target size).
- `MPVController` receives libmpv wakeups on a private queue and forwards parsed events to the main actor.
- The app target compiles in Swift 5 language mode with targeted concurrency checking; the core package uses Swift 6 language mode.

## Images

`ItemImages` picks the right Jellyfin artwork with fallbacks (episode → series poster, season → series, backdrop → parent backdrop, …). `RemoteImage` requests exactly the pixel size a card needs (`maxWidth` on the server, ImageIO downsampling on the device). Memory cache is bounded by decoded bytes (120 MB), disk by URLCache (600 MB, purgeable). Rows and grids are lazy, so a 20 000-episode library only decodes what is on screen.

## Playback stack

See [PLAYBACK.md](PLAYBACK.md). In short:

```
PlaybackCoordinator (MainActor, @Observable)
 ├─ item + media source            (BaseItem, MediaSource)
 ├─ TrackSelector                  default audio/subtitle indices
 ├─ PlaybackDecisionEngine         route + device profile + reasons
 ├─ JellyfinClient.playbackInfo    server confirmation, play session id, URLs
 ├─ PlaybackEngine                 NativePlaybackEngine | AdvancedPlaybackEngine
 ├─ PlaybackSessionReporter        start / progress / stop
 ├─ segments + NextEpisodeResolver skip prompts, countdown, next item
 └─ fallback chain                 engine failure → next route
```

`PlayerScreen` hosts the engine's view controller. The native engine brings its own UI (`AVPlayerViewController`); the advanced engine is overlaid by `AdvancedPlayerOverlay` with `RemoteInputView` capturing Siri Remote gestures.

## Error handling

All failures become `FoyerError(kind:detail:)`. `ErrorPresentation` maps kinds to localized titles/messages; technical detail is only shown when *Debug information* is enabled. Network errors are classified (unreachable, interrupted, certificate) so the message matches the cause.

## Logging

`Log` (categories NETWORK, JELLYFIN, PLAYBACK, SUBTITLE, AUDIO, UI, CACHE) writes to `os.Logger` and to an in-memory ring buffer shown in Settings › Debug › Logs. Tokens, `api_key` parameters and password fields are scrubbed before any sink sees them.

## Accessibility

Cards, buttons and rows carry labels/values (title, progress, watched state). Focus styles respect Reduce Motion; backdrops respect Reduce Transparency. Text uses fixed tvOS-appropriate sizes (system fonts, 21–76 pt).
